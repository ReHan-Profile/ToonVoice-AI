# Public launch checklist

- [ ] Confirm ownership/permission to publish the app source and branding.
- [ ] Review every third-party license, especially the exact FFmpeg binaries/codecs.
- [ ] Complete Android and Windows device testing and resolve release-blocking bugs.
- [ ] Create a signed Android release APK/AAB; store signing keys outside GitHub source.
- [ ] Test Windows installer on clean Windows 10/11 machines.
- [ ] Verify MP4 metadata and playback in multiple players.
- [ ] Prepare screenshots, app description, version notes, support contact, and privacy policy.
- [ ] Decide whether the repository is public and add an explicit source license only if intended.
- [ ] Create a versioned GitHub Release with checksums and release notes.
